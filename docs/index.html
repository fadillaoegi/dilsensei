🌿 DilSensei

Grammar you don't have to think about

Knowing the rule is not the same as saying it in three seconds. DilSensei measures both whether you are right and how long you hesitated, then rebuilds tomorrow's session from the patterns you keep breaking.

How it works

  • Short sessions of sentence-building drills, five to fifteen minutes.
  • A wrong answer is not skipped. It returns later in the same session until you get it right.
  • Mistakes are recorded as grammar patterns, not just as "wrong" — place particles, time-word order, past forms, and so on.
  • One tap builds a fresh session containing only the patterns you are still weak at.
